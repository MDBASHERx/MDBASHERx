# 🚀 Selected Projects

### [FixFlow](https://github.com/Mead-sbait/FixFlow)
A collaborative maintenance request platform connecting users, administrators, and technicians.

- **My contribution:** technician-facing APIs and React interfaces, assigned issue workflows, controlled status changes, comments, notifications, and real-time communication.
- **Stack:** React, TypeScript, Redux Toolkit, Node.js, Express, MongoDB, and Socket.IO.

### [Masari](https://github.com/MDBASHERx/Masari)
An Arabic-first hackathon project for AI-assisted learning and career exploration, previously called My Coach.

- **My contribution:** authentication, student profiles, chat integration, grade recording, project integration, and release preparation.
- **Stack:** React, JavaScript, CSS, Node.js, Express, Supabase Auth, PostgreSQL, and Google Gemini.

### EXO Education
My graduation project at ORT Jerusalem: an education and attendance management platform with student and lecturer dashboards, course schedules, role-based access, and Zoom integration.

- **Stack:** React, JavaScript, HTML, CSS, Node.js, Express, and MongoDB.
